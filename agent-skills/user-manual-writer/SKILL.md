# User Manual Writer Skill

## Required reading
- `docs/standards/user_manual_policy.md`
- `docs/templates/end_user_manual_template.md`
- `docs/standards/safety_policy.md`

## Procedure
1. Identify user-visible changes.
2. Update supported operation only.
3. Mark unverified behavior as `未検証`.
4. Keep safety warnings explicit.
5. Do not expose school/internal/private information.
