# Minimum Constraints

## Non-negotiable
- Do not expose student names, faces, school-internal information, or private network details.
- Do not make COI-risky proposals casually.
- Do not replace safety with spirit, effort, or intention.
- Prefer Reuse → Buy → Make.
- If making, define minimum prototype, verification, and rollback condition.

## For this firmware project
- Safety and misoperation tolerance have priority over convenience.
- Unknown hardware behavior must be marked `未検証`.
- Motor output code must include verification steps and rollback conditions.
