# Bring-up Checklist

## Purpose

このチェックリストは、DinMeter ScrambleMD Testで新しい機能・ドライバ・通信方式をBring-upするときに使用する。

## Scope

対象:

- DinMeter本体の起動確認
- 画面表示
- エンコーダ入力
- CAN / RS485 / PWM / PWM+DIR の段階的確認
- モータドライバProfileの初期試験

対象外:

- 競技本番用制御
- 複数モータ同時制御
- 非常停止回路の代替
- 安全認証

## 0. 作業前確認

- [ ] 作業ブランチを確認した。
- [ ] 変更目的を1文で説明できる。
- [ ] 実モータ出力を追加する作業か、出力なしの作業かを明確にした。
- [ ] 対象デバイスの `docs/hardware/*/spec.md` を確認した。
- [ ] `docs/standards/safety_policy.md` を確認した。
- [ ] `docs/architecture/safety_state_machine.md` を確認した。

## 1. ソフトウェア確認

- [ ] `pio --version` が動作する。
- [ ] `pio project config` が動作する。
- [ ] `pio run` が成功する。
- [ ] 新しい警告が出ていない、または内容を記録した。
- [ ] Arduino IDE互換を壊す変更がない。

## 2. DinMeter単体確認

- [ ] USBのみで起動する。
- [ ] 画面にタイトルが表示される。
- [ ] `State: Disabled` が表示される。
- [ ] `Target: 0` が表示される。
- [ ] Serialログが出る。
- [ ] エンコーダ回転でtargetが変化する。
- [ ] `target == 0` のときだけ長押しでArmedへ遷移する。
- [ ] Armed中の短押しまたは長押しでDisabledへ戻る。
- [ ] 実モータ出力がないことを確認した。

## 3. 実出力なしの通信Bring-up

CAN / RS485 / PWMスタブを追加した場合:

- [ ] 実モータ・ドライバを接続していない。
- [ ] 物理出力関数が呼ばれない状態でビルド確認した。
- [ ] ダミー/ログ出力だけで動作確認した。
- [ ] `Disabled` で出力がゼロまたは未送信であることを確認した。
- [ ] `Fault` で出力がゼロまたは未送信であることを確認した。

## 4. 実機接続前チェック

実モータまたはドライバを接続する前に、必ず確認する。

- [ ] 対象Profileが正しい。
- [ ] 電源電圧が対象機器の許容範囲内。
- [ ] 電流制限付き電源または安全な電源構成である。
- [ ] GND共通または絶縁方針が明確。
- [ ] 信号線の向きが正しい。
- [ ] CAN_H / CAN_L、RS485 A/Bを取り違えていない。
- [ ] 終端抵抗が必要な場合、設定を確認した。
- [ ] モータ・車輪・ギア・ベルトが安全に固定されている。
- [ ] 回転部に手やケーブルが接触しない。
- [ ] 指導者またはメンターが立ち会っている。

## 5. 初回実出力試験

- [ ] target = 0で起動した。
- [ ] `State: Disabled` を確認した。
- [ ] 電源電圧を記録した。
- [ ] 電流制限値を記録した。
- [ ] 最小targetから試験した。
- [ ] 異常音、異常発熱、振動がない。
- [ ] 停止操作で停止できる。
- [ ] 電源OFFで安全に停止できる。
- [ ] 試験結果を `docs/operations/hardware_test_log_template.md` に従って記録した。

## 6. 撤退条件

以下のいずれかに該当した場合、試験を中止する。

- [ ] 意図しない回転が発生した。
- [ ] DisabledまたはFaultで出力が残った。
- [ ] 通信timeoutやbus-offが復帰不能になった。
- [ ] 異常発熱が発生した。
- [ ] 異臭、煙、火花が出た。
- [ ] モータ・治具・配線が固定できていない。
- [ ] 原因不明の挙動が再現した。

中止後は、原因が特定されるまで実モータ接続試験を再開しない。
