# DD Motor Preflight Checklist

## 目的

DDモータ（モータドライバ内蔵ダイレクトドライブモータ）の実機動作確認に入る前に、共通の安全・接続・通信確認事項を整理する。本チェックリストは、RobStride EDULITE 05 および DDT-M0602C234 の両方に適用する。

## 試験範囲

- **Phase 1**: 通信確認（CAN / RS485接続の確立、ID確認、応答有無）
- **Phase 2**: Telemetry取得確認（バス電圧、温度、状態値などの受信・解釈）

> [!CAUTION]
> Phase 1 および Phase 2 では、**Enableコマンド（駆動許可）は送信しない**。
> 速度指令（spd_ref）、トルク指令、電流指令も送信しない。

## 電源

| 項目 | 確認内容 | チェック |
|---|---|---|
| モータ電源電圧 | モータspec記載の動作電圧範囲内であること。実測値を記録する | [ ] |
| 電流制限 | 電源側の電流制限を設定していること。値を記録する | [ ] |
| 電源遮断手段 | すぐに電源を遮断できる物理的な手段（スイッチ / プラグ抜き等）を手元に用意していること | [ ] |
| DinMeterから供給しない | モータ電源をDinMeterのPort A/B (5V) から供給していないこと | [ ] |
| DinMeter電源 | DinMeterはUSB等の独立電源で動作していること | [ ] |

## 安全確認

| 項目 | 確認内容 | チェック |
|---|---|---|
| Enableコマンド非送信 | Phase 1/2 では Enableコマンドを送信しないこと | [ ] |
| 速度/トルク/電流指令非送信 | Phase 1/2 では spd_ref, トルク指令, 電流指令を送信しないこと | [ ] |
| 軸拘束なし | モータ軸が自由に回転できる状態であること（拘束していないこと） | [ ] |
| 手・指の安全 | 手や指を負荷・停止・反力として使わないこと。低トルク設定であっても禁止 | [ ] |
| 回転部の安全距離 | 手、ケーブル、衣服がモータ軸・筐体から離れていること | [ ] |
| 立会い | 指導者またはメンターが立ち会っていること（推奨） | [ ] |
| 電源遮断手段 | すぐに電源を遮断できる手段が手元にあること | [ ] |
