# Documentation Policy

When code changes affect user operation, screen display, wiring, supported device, profile behavior, or safety behavior, update documentation in the same change.

Required updates:
- `docs/manuals/user_manual.md`
- `docs/manuals/quick_start.md` if basic operation changes
- `docs/manuals/troubleshooting.md` if errors or faults change
- relevant `docs/hardware/*/spec.md` if hardware assumptions change
